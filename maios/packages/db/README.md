# @maios/db

Canonical PostgreSQL schema — the durable source of relational truth (plan §4).
Close, the MAIOS app, n8n, reporting, and the owned SIP stack are projections or
consumers of this model.

## Migrations

Plain SQL in `migrations/`, applied in filename order:

| File | Contents |
|---|---|
| `0001_tenancy_platform.sql` | tenants, users, roles, memberships, service accounts, connections, external_object_map, transactional outbox, webhook inbox, sync jobs, dead letters, idempotency keys, audit, feature flags |
| `0002_crm.sql` | companies, people, contact_channels, pipelines, leads, opportunities + stage history, activities, tasks, notes, person merges |
| `0003_tracking_attribution.sql` | sites, visitors, sessions, campaign hierarchy, consent, immutable touch_events, form submissions, identity associations, conversions, attribution runs/results/rollups |
| `0004_communications.sql` | phone numbers, routing, calls/legs/events, dispositions, recordings, messages, number leases |
| `0005_agents_knowledge_assets.sql` | assets + access audit, documents/chunks/vector refs, agent registry/runs/tool calls/approvals/evaluations |
